“基于图像和深度学习的内涝监测”为核心，将整体任务拆解为数据集构建、目标检测模型开发、语义分割模型开发、交互系统集成四大模块，明确各步骤的工具、算法与处理目标，确保流程可落地、结果可验证。
⑴图像标注与数据集构建
①明确内涝图像中 “车辆 - 水面” 的视觉特征，车辆淹没部位的三类区分（车轮顶部及以下、车轮顶部至车窗下沿、车窗及以上）、水面与地面 / 道路的边界特征；
②打开 X-Anylabeling，导入待标注图像，选择 “矩形框标注” 工具，框选单张图像中所有车辆，确保框体完整覆盖车辆区域（不遗漏车轮 / 车窗）。为每个矩形框分配类别标签（0：车轮顶部及以下、1：车轮顶部至车窗下沿、2：车窗及以上）。导出标注文件为 YOLO 格式（.txt 文件，含框体坐标与类别），与图像文件按 “一一对应” 命名；
③选择 “多边形标注” 工具，沿水面与背景的真实边界点击，形成闭合多边形，为多边形标注分配类别标签（0：背景、1：水面）；导出标注文件为掩码格式（.png 文件，像素值 0 代表背景、1 代表水面），确保掩码分辨率与原图像一致；
④分别对 “车辆淹没部位数据集”“水面分割数据集” 按划分比例（训练集 70%、验证集 20%、测试集 10%），执行划分。

⑵目标检测模型开发，实现车辆淹没部位判别
①阅读 YOLOv11、RT-DETR核心文献，总结两种模型在 “小目标检测”“遮挡目标检测” 上的优势；
②确定开发框架，确保框架支持自定义数据集训练；
③配置稳定的训练环境，避免版本冲突，基于预训练权重微调，适配车辆淹没部位检测；
④设置相应epoch，和学习率，适当微调参数，最终得到训练模型。；
⑤分别计算训练集、验证集、测试集的准确率(accuracy)、精确率(precision)、召回率(recall)、F1-Score评价模型的性能；
⑥计算训练时间和测试时间。

⑶语义分割模型开发，实现水面分割
①阅读 YOLOv11、deeplabv3+、U-Net核心文献，总结三种模型在语义分割上的优势；
②确定开发框架，确保框架支持自定义数据集训练；
③配置稳定的训练环境，避免版本冲突，基于预训练权重微调，适配水面的检测；
④设置相应epoch，和学习率，适当微调参数，最终得到训练模型；
⑤分别计算训练集、验证集、测试集的平均像素准确率（mPA）和平均交并比（mIoU）评价模型的性能，最终选择性能较高的两个模型；
⑥计算训练时间和测试时间。

⑷交互系统集成
选择HTML、CSS与java语言开发积水识别和车辆淹没部位判别系统，使系统具有交互界面，同时满足以下基本功能要求：
·支持图像的上传，支持目标检测和图像分割结果的下载；
·图像和目标检测和图像分割结果的左右分屏显示；
·支持不同淹没部位车辆的数量统计；
·支持选择和调用不同的模型。
